# Install Read Aloud Controls for ChatGPT

1. Download `chatgpt-read-aloud-controls-unpacked.zip` from the
   [latest release](https://github.com/Tiffufu/chatgpt-read-aloud-controls/releases/latest).
2. Extract the ZIP and move the `chatgpt-read-aloud-controls` folder to a permanent location.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode** in the upper-right corner.
5. Click **Load unpacked** and select the extracted `chatgpt-read-aloud-controls`
   folder. It contains `manifest.json`, `src`, and `icons`.
6. Refresh any open `chatgpt.com` tabs and start **Read Aloud** on a response.
7. Optionally pin the extension from Chrome's extensions menu to access settings.

Select the extracted folder, rather than the ZIP or its `src` subfolder.
Keep the folder in place while the extension is installed.

## Update

Download and extract the latest release, then replace the extension files in
that same permanent folder. Open `chrome://extensions`, click **Reload** on the
extension card, and refresh ChatGPT tabs. Unpacked installations are updated
manually; downloading a new ZIP does not update an existing installation.
